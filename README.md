# accounting
한국외국어대학교 노동조합 회계

## Firebase 설정

이 앱은 담당자 인증에 Firebase Authentication의 Google 로그인을, 공용 자료 저장에 Cloud Firestore를 사용합니다.

1. Firebase Console에서 **Authentication → 로그인 방법 → Google**을 사용 설정하고 Firestore 데이터베이스를 만듭니다.
2. **Authentication → 설정 → 승인된 도메인**에 배포된 사이트의 호스트명을 추가합니다. Google 로그인은 HTTPS 사이트에서 실행해야 합니다. `file://`로 직접 여는 방식은 지원하지 않습니다.
3. Firebase 웹 앱 설정을 [firebase-config.js](./firebase-config.js)에 둡니다. 웹 앱 설정은 공개 식별 정보이며, Admin SDK 서비스 계정 키나 비공개 키는 절대 넣지 마세요.
4. [firestore.rules](./firestore.rules)의 규칙을 **Firestore Database → 규칙**에 게시합니다.
5. 담당자가 Google로 최초 로그인하면 화면에 Firebase Authentication UID가 표시됩니다. Firestore에 `allowedUsers/{UID}` 문서를 만들면 해당 계정에 읽기·쓰기 권한이 부여됩니다. 문서 ID는 로그인 화면의 UID와 정확히 일치해야 합니다. 관리 참고용으로 `email` 필드를 추가할 수 있습니다.

Firestore의 `accountingData` 컬렉션에 연도별 자료가 저장되고 브라우저 간 실시간으로 동기화됩니다. Firestore에 자료 문서가 없을 때 같은 브라우저의 이전 로컬 자료가 있으면 먼저 복사하고, 없으면 기본 자료를 초기화합니다. 기존 거래 내역의 관·항·목 분류도 자동으로 이전됩니다.

**사용자 관리** 탭에서 결산 담당자 이름을 추가하거나 삭제할 수 있고, 담당자별 은행명과 계좌번호를 따로 입력해 저장할 수 있습니다. 은행 정보는 모든 허가된 앱 사용자와 공유됩니다. 등록한 이름은 결산 관리의 담당자 입력란에서 드롭다운으로 선택할 수 있으며, 목록에 없는 이름도 직접 입력할 수 있습니다. 담당자 목록은 회계연도와 관계없이 공유되며, 목록에서 이름을 삭제해도 기존 거래 내역의 담당자 표기는 유지됩니다.

결산 내역 상태는 **입력완료 → 제출완료 → 지급완료**이며, 각 단계에서 선택한 내역을 일괄 처리할 수 있습니다. 모든 허가된 로그인 사용자가 제출·반려·지급완료 승인을 할 수 있습니다. 한 번에 처리하는 내역의 담당자는 반드시 같은 한 사람이어야 합니다. 선택한 입력완료 내역을 제출하면 해당 묶음에 회계연도를 넘어 1부터 계속 증가하는 관리번호를 부여하고, 지급 승인 시 승인일(현지 날짜)과 당일 순번을 조합한 관리번호(예: `20261002001`)로 갱신합니다. 각 번호는 Firestore 트랜잭션으로 중복을 방지해 발급하며, 보고서와 내역 목록에 현재 관리번호를 표시합니다. 입력완료·제출완료 내역은 보고서로 열람할 수 있으며, 지급신청서에는 담당자의 등록된 은행명·계좌번호, 거래별 결제일·내역·지급처·금액·목, 합계와 영수증 첨부란을 표시합니다. 제출완료 내역을 지급완료 승인하면 승인자와 승인 시각이 표시된 지급 승인 도장이 포함된 PDF 한 개가 생성됩니다. 파일명은 `YYYYMMDD_담당자명_총액원.pdf` 형식입니다. 기존 `승인됨` 자료는 지급완료로, 기존 `승인대기` 자료는 입력완료로 자동 이전됩니다.

새 내역 입력의 날짜 항목은 결제일로 표시합니다. `대학노조회비`는 새 내역의 세부 계정과목 선택 목록에서 제외됩니다.

결산 관리에서는 새 내역 입력이 입력 완료 처리 목록보다 먼저 표시됩니다. 내역을 승인할 때 지출은 **지급완료**, 수입은 **확인완료**로 각각 기록하며 보고서 합계에 반영합니다. 보고서의 예산 대비 실적·세부 거래·상위 지출 표에는 합계행을, 예산 관리의 분류표에는 수입·지출·전체 예산 합계를 표시합니다.

공유 드라이브 PDF 저장을 사용하려면 Google Cloud Console에서 이 Firebase 프로젝트의 **Google Drive API**를 사용 설정하고, 승인하는 Google 계정에 공유 드라이브 대상 폴더의 파일 추가 권한을 부여하세요. 승인 시 Google Drive 파일 접근 권한 동의를 요청합니다. 저장 대상 폴더 ID는 앱의 `DRIVE_FOLDER_ID` 설정과 일치해야 합니다. PDF 생성에는 html2pdf.js CDN을 사용합니다.

예산 관리에서는 구분·관·항·목·예산을 한 표에서 행별로 관리합니다. 예산 입력 금액은 천 단위 쉼표로 표시됩니다. 관·항 이름은 각각 `관`, `항`을 구분하는 접미사 없이 입력하며, 기존 이름 끝의 `_관`, `_항`은 자동 정리됩니다. 새 분류는 **목 추가**로 행을 만든 뒤 각 열을 입력하고 저장합니다. 예산은 회계연도별로 수입과 지출의 각 목에 입력하며, 새 회계연도에서는 **전년도 예산 불러오기**를 눌러 현재 분류와 일치하는 목의 금액을 채운 다음 변경 항목을 수정하고 **분류 및 예산 저장**을 눌러 저장합니다. 수입·지출 예산은 서로 구분해 저장하며, 보고서 하단의 예산 대비 실적 표에는 예산 관리의 구분·관·항·목 순서대로 수입과 지출 목별 예산·집행액을 표시합니다. 기존 관별 예산 데이터가 있으면 초기 이전 시 소속 지출 목에 균등 배분하므로, 이전 안내가 표시되면 금액을 확인하고 조정하세요.
